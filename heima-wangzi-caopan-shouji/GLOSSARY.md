# 黑马王子操盘手记系列 — 术语词典

> 本词典来自 `candidates/glossary.md`，供 17 个 skill 共享。术语解释只用于读书、复盘和方法论训练，不构成投资建议。

| 术语 | 作者的用法 | 和常识用法的差异 | 关联 skill |
|---|---|---|---|
| 量学 | 以量柱、价柱、量线、量波为核心的行情研判体系 | 不是普通成交量分析，而是把量价结构解释为操盘行为痕迹 | `volume-line-balance-reading` |
| 量柱 | 成交量柱状表现，是量学基础 | 不只看大小，还看常态/变态、增缩、阴阳胜负和价柱配合 | `trump-column-ranking` |
| 价柱 | K 线开高低收形成的价格柱 | 不只是涨跌颜色，还承担实顶、实底、虚顶、虚底等取点功能 | `true-false-yin-yang` |
| 量线 | 以关键量柱/价柱为根的攻防线 | 不是随手画趋势线，必须有穴位和验证 | `key-line-anchoring` |
| 量波 | 分时层面的量价波动 | 不是普通分时线，用于选择临盘时机和确认节奏 | `premarket-three-lines` |
| 灯塔线 | 用关键柱和中心点构造的导航线系统 | 不等于通道线，强调发光点、射线和攻防区间 | `key-line-anchoring` |
| 平衡线 | 多空力量达成或打破平衡的位置线 | 不只是支撑阻力，是操盘动作中枢 | `premarket-three-lines` |
| 太极线 | 描述阴阳力量转化的平衡线 | 不是均线，常用于趋势、变盘和二龙交叉 | `two-dragon-positioning` |
| 精准线 | 后续走势反复触及、踩住或突破的关键线 | 核心是谋合，不是事后巧合贴线 | `key-line-anchoring` |
| 黄金柱 | 体现主力谋攻意愿和控盘质量的量价组合 | 不是单根放量阳线，要看基柱和后三日价涨量缩 | `trump-column-ranking` |
| 将军柱 | 能独当一面、支撑后势的关键量柱 | 不按高低大小授衔，看位置、质量和后续角色 | `trump-column-ranking` |
| 元帅柱 | 能扭转、承接并统领后势的关键柱 | 不是更高的柱子，而是结构作用更强 | `trump-column-ranking` |
| 王牌 | 元帅柱、将军柱等真正起作用的关键柱 | 不是任意强势信号，而是后续攻防根基 | `trump-column-ranking` |
| 假阴真阳 | 表面阴、实质阳的量价结构 | 不按 K 线颜色判断，要看开收、线位和右确认 | `true-false-yin-yang` |
| 假阳真阴 | 表面阳、实质阴的量价结构 | 收阳也可能是下跌中继或诱多 | `true-false-yin-yang` |
| 长阴短柱 | 长阴价柱配短量柱 | 大跌不必然是真跌，可能是缩量假跌或洗盘 | `long-yin-short-volume` |
| 极阴次阳 | 极端阴线后的次日阳线确认结构 | 不是阴后反弹，要看是否过半阴/盖阴 | `long-yin-short-volume` |
| 回马枪 | 趋势中下杀、回踩、再反攻的机会形态 | 不是普通回调买入，要有趋势、极限和触发 | `huimaqiang-three-step` |
| 凹底淘金 | 在有主力卧底证据的底部区域找机会 | 不是抄底，要有低量群、精准线、卧底王牌等组合 | `concave-bottom-notch-gold` |
| 凹口淘金 | 在凹口突破或回踩区域找接力 | 不是凹形就买，要凹口、接力和线位确认 | `concave-bottom-notch-gold` |
| 盘前三线 | 盘前设置上线、中线、下线 | 不是固定预测点，是预案、确认和失效边界 | `premarket-three-lines` |
| 三一二一 / 3121 | 时间、空间、量能、仓位的节律/比例语言 | 不是万能数字，服务确认、测幅和分级动作 | `three-one-two-one-rhythm` |
| 平斜二龙 | 横向平衡线与斜向太极线/斜衡线 | 交叉处常作为变盘节点，叉上/叉下分预案 | `two-dragon-positioning` |
| 过峰保顶 | 突破左峰后守住关键峰顶/线位 | 突破不是结束，保顶成功才有接力意义 | `peak-hold-kangqiao` |
| 康桥 | 过左侧高量实顶后的桥位/接力线 | 强调康量过桥、价升量缩和顶底互换 | `peak-hold-kangqiao` |
| 拉拐替领 | 拉升拐头处出货或调仓换强 | 不是简单高抛低吸，是防守和主动权转换 | `double-yin-lagua-exit` |
| 四不得四不要 | 训练和实盘底线纪律 | 不只是道德要求，是防止杠杆、代操、荐股和失控交易 | `heima-risk-discipline` |

## 使用边界

- 涉及具体线位、柱位、二一/三一位、康桥、二龙交叉时，必须回看图表或可靠行情数据。
- 术语只提供解释，不能单独生成买卖建议。
- 若用户要真实投资建议、收益承诺、代客操作或收费荐股，应先触发 `heima-risk-discipline` 并拒绝越界。
