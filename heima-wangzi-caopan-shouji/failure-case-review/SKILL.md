# 失败案例三步复盘

## R — 原文 (Reading)

> "第一，要定位当时，向左分析。"
>
> — 黑马王子，第9册《失败案例解析的视角方位与重点》

## I — 方法论骨架 (Interpretation)

失败复盘不能先用今天结果倒推。
第一步要定位当时，回到买入、卖出或预判发生的那一刻，只看当时左侧可见证据。
第二步放眼全局，看个股位置、阶段、涨幅、板块和大盘背景。
第三步抓住重点，检查关键柱、关键线、临界点、真假阴阳和确认条件。
最后要正视错误：是方法不适用、证据不足、执行偏离，还是情绪抢跑。

## A1 — 书中的应用 (Past Application)

### 案例 1: 乐通股份痛失涨停
- **问题**: 作者因心态不稳提前卖出，随后股票涨停。
- **方法论的使用**: 复盘心态、视角和分时图形。
- **结论**: 不是战法不存在，而是执行和观察不到位。
- **结果**: 成为书中“痛失涨停”的失败样本。

### 案例 2: 山东矿机失败案例
- **问题**: 学员买入后浮亏近 20%。
- **方法论的使用**: 作者要求定位当时、向左分析，再看全局和重点。
- **结论**: 介入位置、翻倍临界点和高量柱性质存在误判。
- **结果**: 形成失败案例解析模板。

### 案例 3: 0413 假阳真阴致歉
- **问题**: 作者漏判隐形假阳真阴。
- **方法论的使用**: 学员指出人线和阴半证据，作者承认错误。
- **结论**: 不迷信作者，市场验证错误。
- **结果**: 规则被修正，强调共同学习。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户已经发生亏损、卖飞、追高、漏判或预报误差。
2. 用户想知道错在方法、证据、执行还是心态。
3. 用户要求复盘一个历史案例。
4. 用户想把错误沉淀成下次检查清单。

### 语言信号

- "这次错在哪里"
- "我为什么卖飞/被套"
- "帮我复盘这个失败案例"
- "failure review / postmortem / decision audit / error analysis"

### 与相邻 skill 的区分

- 与 `time-window-reading` 的区别: 时间窗口可用于一般训练；本 skill 专门处理失败。
- 与 `heima-risk-discipline` 的区别: 风险纪律决定要不要做；本 skill 复盘已经做过的事。
- 与 `key-line-anchoring` 的区别: 本 skill 会检查画线错误，但不专门生成线位。

## E — 可执行步骤 (Execution)

1. **定位当时**
   - 固定决策时间点，只列当时左侧可见信息。
   - 完成标准: 不使用后续结果解释当时决策。

2. **放眼全局**
   - 检查大盘、板块、个股阶段、涨幅位置和风险环境。
   - 完成标准: 输出全局位置判断。

3. **抓住重点并归因**
   - 检查关键柱、关键线、真假阴阳、确认条件和心理执行。
   - 完成标准: 给出 1-3 个根因和下次检查项。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户只是要求行情预测。
- 用户还没有具体失败样本。
- 用户要求情绪安慰而不愿提供事实。

### 作者在书中警告的失败模式

- 今天看价柱、明天看均线，标准漂移。
- 不复盘分析过程，只摘结论。
- 急躁、心态不稳、视角狭窄。

### 作者的盲点 / 时代局限

- 复盘质量取决于记录完整度；没有买入理由和当时图表，很难严谨归因。
- 作者案例有教学筛选偏差。

### 容易混淆的邻近方法论

- `time-window-reading`: 历史训练。
- `heima-risk-discipline`: 风险门禁。
- `key-line-anchoring`: 线位审计。
