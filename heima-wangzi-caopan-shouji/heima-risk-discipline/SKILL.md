# 四不得四不要风险纪律

## R — 原文 (Reading)

> "不得代客理财，不得借钱炒股，不得收费荐股，不得贬低他人。"
>
> — 黑马王子，第3册《黑马王子为师之道》

## I — 方法论骨架 (Interpretation)

这不是道德口号，而是交易训练的前置防火墙。
作者认为，普通人一旦把技术和外部金钱、他人期待、收费关系绑在一起，判断会立刻变形。
代客理财会引入责任压力；借钱炒股会放大恐惧和贪婪；收费荐股会逼你表演正确；神化作者会让你放弃自己的验证。
所以进入任何实盘、加仓、荐股、代操之前，先检查这些底线。
没有训练成绩、没有止损线、心态混乱、连续亏损时，正确动作不是再拼一把，而是退回训练场。

## A1 — 书中的应用 (Past Application)

### 案例 1: 炒股的金钥匙
- **问题**: 学员学到一点技术后，容易想代客理财、借钱放大或收费荐股。
- **方法论的使用**: 作者把这些动作列成“四不得”，先从关系和资金结构上堵住失控源。
- **结论**: 技术没有稳定前，不能把自己暴露在外部压力里。
- **结果**: 这条纪律在后续多册中反复作为训练边界出现。

### 案例 2: 成绩下降暂停实盘
- **问题**: 实盘成绩变差后，交易者想靠下一笔扳回。
- **方法论的使用**: 作者要求一旦发现成绩下降就暂停实盘，因为这时心态已经乱。
- **结论**: 停手也是操作，先保住训练状态。
- **结果**: 该反例被并入后续失败复盘和风险纪律。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户想把书中战法用于实盘前，需要先检查是否越过风险底线。
2. 用户提到代客理财、借钱炒股、融资、收费荐股、公开推荐股票。
3. 用户连续亏损、心态乱、想翻本，仍然想继续操作。
4. 用户把作者或老师的结论当成指令，不想自己验证。

### 语言信号

- "我能不能直接实盘"
- "朋友出钱让我帮他做"
- "要不要融资/借钱干一把"
- "我连续亏了，要不要加仓扳回来"
- "Can I trade this live / use leverage / give paid stock tips?"

### 与相邻 skill 的区分

- 与 `double-yin-lagua-exit` 的区别: 本 skill 是交易前的风险门禁；后者是盘面已经出现风险信号后的退出流程。
- 与 `failure-case-review` 的区别: 本 skill 判断要不要做；后者复盘已经做错的判断。
- 与 `time-window-reading` 的区别: 本 skill 管纪律；后者管如何读历史材料和训练判断。

## E — 可执行步骤 (Execution)

1. **先判红线**
   - 检查是否涉及代客、借钱、杠杆、收费荐股、承诺收益、公开跟单。
   - 完成标准: 每一项明确标为 `触发` / `未触发`。

2. **再判训练资格**
   - 检查是否有稳定模拟成绩、明确止损、可复盘记录、情绪稳定。
   - 完成标准: 能说明“为什么现在具备/不具备实盘资格”。
   - 判停条件: 若红线已触发，直接输出停止建议，不进入战法分析。

3. **给出降级动作**
   - 把实盘、荐股、加仓等动作降级为模拟、纸面预案、复盘或观望。
   - 完成标准: 输出一个不涉及真实买卖建议的训练动作。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 用户只是在问术语定义，应使用 `GLOSSARY.md` 或相关方法 skill。
- 用户已经给出具体行情图并要求判断盘面信号，应先用读盘、三线或出货类 skill。
- 用户要求真实投资建议、收益承诺、代操方案时，不应给建议，应明确拒绝越界。

### 作者在书中警告的失败模式

- 代客理财把交易者变成金钱奴隶。
- 借钱炒股放大贪婪和恐惧。
- 收费荐股把技术变成枷锁。
- 神化作者、跟风作者点评股票，导致放弃独立判断。

### 作者的盲点 / 时代局限

- 作者样本主要来自 2009-2017 年 A 股，不等于任何市场都能复制。
- 书中训练案例不能替代合规投资顾问和账户级风控。

### 容易混淆的邻近方法论
