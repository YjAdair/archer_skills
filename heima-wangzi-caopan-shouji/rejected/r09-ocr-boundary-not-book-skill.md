# Rejected: OCR 边界不是书内方法论 skill

- candidates: ce21
- decision: 不独立成 skill，作为全项目 Boundary 使用。

## 三重验证

- V1_cross_domain: 不适用。该项来自阶段 0 的处理边界，不是书中作者方法。
- V2_predictive_power: 通过。它能提醒具体画线规则必须回看图表。
- V3_exclusivity: 不通过。它是本次数据处理限制，不是黑马王子方法论。

## 后续用途

凡涉及具体线位、柱位、图形关系的 skill，都要写入该边界：OCR 文本不足以确认精确图表关系，必须回看页图或重建行情数据。
