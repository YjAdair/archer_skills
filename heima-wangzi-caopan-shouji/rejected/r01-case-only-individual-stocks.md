# Rejected: 个股案例不独立成 skill

- candidates: c01-c24
- decision: 降级为 A1 案例素材，不独立成 skill。

## 三重验证

- V1_cross_domain: 部分通过。案例能证明某个方法出现过，但单个股票案例本身不是跨场景方法论。
- V2_predictive_power: 不通过。单个案例通常只能回答“当时为什么这样做”，不能稳定推导新场景。
- V3_exclusivity: 不通过。独特性属于背后的方法，如双阴出货、盘前三线、回马枪，不属于个股名称或历史收益。

## 后续用途

这些案例会在阶段 2 作为各 skill 的 A1 使用：例如 c05/c06 支撑“双阴出货”，c19/c22 支撑“盘前三线”，c08/c18 支撑“失败案例三步复盘”。
