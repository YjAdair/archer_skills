- id: f01
  title: 时间窗口三步阅读法
  type: framework
  source_chapter: 操盘手记（六）｜通过“时间窗口”采撷“操盘绝活”
  source_quote: |
    "以这个时间为起点，先用你自己的眼光预判未来的行情，并记下你的预判结论。"
  summary: |
    这是一套把读者放回历史现场的读盘训练框架。
    第一步只看当时行情，不用事后结果污染判断。
    第二步先写下自己的方向、点位和后续走势预判。
    第三步再对照作者当时预判与真实走势，反推其取点、画线和推理依据。
    它的价值在于把阅读变成“预测-对照-校正”的闭环训练。
  tags: [reading-method, time-window, forecast-training, review]

- id: f02
  title: 量价阴阳真假虚实动态平衡框架
  type: framework
  source_chapter: 操盘手记（一）｜股市量学 ABC
  source_quote: |
    "量柱和价柱的不同搭配和组合、阴阳虚实的平衡与失衡，往往决定了其后的走势和相应的幅度。"
  summary: |
    该框架不孤立看价格，也不孤立看成交量。
    它把量柱、价柱、阴阳、真假、虚实放在一个动态平衡系统中观察。
    平衡说明市场暂时稳定，失衡则暴露力量转移和主力行为。
    推理重点是识别量价搭配背后的真实意图，而不是表面涨跌。
    可迁移为任何复杂信号系统中的“表层现象-底层力量”分析框架。
  tags: [mental-model, volume-price, dynamic-balance, market-reading]

- id: f03
  title: 量线生根与穴位取点框架
  type: framework
  source_chapter: 操盘手记（九）｜太极线威力再现
  source_quote: |
    "量学的量线不是随意画的，一定要找到最好的穴位才能画出最好的量线。"
  summary: |
    该框架把画线视为证据定位，而不是主观连线。
    量线必须从关键量柱、价柱或特殊穴位生根。
    取点遵循先实后虚、因势取点，用已发生的关键位置约束未来判断。
    线的意义来自市场在这些点位上的真实攻防，而不是图形美观。
    可迁移为任何趋势判断中的“先找锚点，再建边界”方法。
  tags: [line-drawing, anchor-points, evidence, trend]

- id: f04
  title: 盘前三线预案与中线中枢框架
  type: framework
  source_chapter: 操盘手记（二）｜盘前三线与操盘中枢
  source_quote: |
    "中线是我们操盘的行为中枢，也就是决定如何操盘的神经中枢。"
  summary: |
    该框架要求盘前先设上线、中线、下线，而不是盘中临时反应。
    中线承担多空分水岭和行为中枢的角色。
    价格在三线规划内运行时，按预案执行；远离三线时再调整策略。
    上线、下线不是静态点位，而是攻防强弱的观察边界。
    可迁移为“事前边界-事中执行-偏离修正”的决策框架。
  tags: [decision-boundary, premarket-plan, three-lines, execution]

- id: f07
  title: 回马枪三步破解框架
  type: framework
  source_chapter: 操盘手记（一）｜看准大方向，破解回马枪
  source_quote: |
    "破解回马枪，第一要趋势不变；第二要预测它最多在什么位置回马；第三要随时盯住回马的一瞬间。"

    第二步预判回踩极限位置，通常结合关键线、黄金线或精准线。
    第三步等待回马瞬间的确认，而不是提前主观押注。
    可迁移为趋势系统中的“方向确认-极限测算-触发执行”框架。
  tags: [reversal, pullback, confirmation, timing]

- id: f08
  title: 长阴短柱假跌推理框架
  type: framework
  source_chapter: 操盘手记（一）｜长阴短柱与真假下跌
  source_quote: |
    "‘长阴短柱’就是典型的‘假跌’。其‘假跌’的特征就是缩量，主力不出货。"
  summary: |
    该框架通过价跌与量缩的背离判断下跌性质。
    正常下跌往往量价同步，而长阴短柱说明价格打压但成交不足。
    成交不足意味着主力未必真实出货，可能是洗盘或诱空。
    判断时还要结合回踩位置是否落在精准线、黄金线等关键支撑。
    可迁移为“表面压力-真实参与度-行为意图”的反事实推理。
  tags: [false-move, volume-price-divergence, inference, washout]

    其核心是区分表面阴阳与真实攻防方向。
    可迁移为“表象分类-结构校验-后续确认”的真假识别方法。

- id: f12
  title: 收评兼预报两段式推理框架
  type: framework
  source_chapter: 操盘手记（六）｜收评兼预报
  source_quote: |
    "所谓‘收评兼预报’，就是根据当天的日象预判明天的日象。"
  summary: |
    该框架把每日复盘拆成当日小结和次日预判两段。
    当日小结负责归纳日象、量柱、价柱、线位和市场状态。
    次日预判负责提出条件化推演，而不是给孤立结论。
    第二天再用实际走势校验前一日判断，形成连续修正。
    可迁移为任何高频决策中的“复盘-预判-验证”循环。
  tags: [daily-review, forecast-loop, reasoning, validation]

  source_quote: |
    "主力不动，我们不动；主力一动，我们就要紧跟。"

  source_quote: |
    "解答这个问题的方法可以参见……即定位当时、放眼全局、抓住重点。"

    抓住重点，最后检查关键穴位、临界点和主力点穴是否成立。
