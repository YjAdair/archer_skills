# Principle Candidates

- id: p01
  title: 时间窗口三步阅读法
  type: principle
  source_chapter: 第1册 Page 5-6 · 通过“时间窗口”采撷“操盘绝活”
  source_quote: |
    "以这个时间为起点，先用你自己的眼光预判未来的行情，并记下你的预判结论。"
  summary: |
    阅读操盘手记时，不能直接看作者结论。
    先把行情切回文章发表当日，独立预判大盘方向、点位和个股趋势。
    再对照作者当时的预判与后续走势，找出自己的判断差距。
    这个规则把读书变成训练，而不是抄答案。
    适用于复盘历史行情、训练盘前预案和校准量学眼光。
  tags: [reading-method, backtest, independent-judgment]

- id: p02
  title: 四不得风控底线
  type: principle
  source_chapter: 第3册 Page 15 · 黑马王子为师之道
  source_quote: |
    "不得代客理财，不得借钱炒股，不得收费荐股，不得贬低他人。"
  summary: |
    交易能力不外包，也不拿别人的钱和信任做压力杠杆。
    不代客理财，避免收益分配和亏损责任扭曲判断。
    不借钱炒股，避免杠杆放大情绪和爆仓风险。
    不收费荐股，避免从研究者变成卖结论的人。
    不贬低他人，保持学习关系和复盘环境的开放性。
  tags: [risk-discipline, no-leverage, ethics, checklist]

- id: p03
  title: 未过训练门槛不实盘
  type: principle
  source_chapter: 第3册 Page 15 · 黑马王子为师之道
  source_quote: |
    "在模拟炒股中没有战胜80%以上的对手时，不要轻易实盘；在涨停预报成功率没有达到60%的时候，不要轻易实盘。"
  summary: |
    实盘不是学习入口，而是训练结果的验证场。
    模拟炒股不能稳定战胜多数对手时，不应投入真钱。
    涨停预报成功率没有达到明确门槛时，也不应贸然进场。
    如果实盘成绩下降或心态混乱，应暂停交易。
    这条规则把“想交易”转换成“先证明自己具备交易资格”。
  tags: [simulation-first, readiness, discipline]

- id: p04
  title: 未设止损不下单
  type: principle
  source_chapter: 第1册 Page 215-216 · 关注“长腿踩线”股票的涨停分化（1206盘前）
  source_quote: |
    "未思进，先思退；先保本，再赚钱；先图生存，后谋发展。"
  summary: |
    每次下单前先定义能承受的亏损，而不是先想能赚多少。
    止损位必须在买入前确定，不能等亏损发生后临时找理由。
    未研究、大市不好、情绪冲动、下跌趋势和无止损都构成不下单条件。
    这不是悲观，而是把亏损控制在自己能管理的范围。
    适用于任何新仓、加仓和短线反弹交易。
  tags: [stop-loss, pre-trade-checklist, capital-preservation]

- id: p05
  title: 不信人，只信量柱
  type: principle
  source_chapter: 第1册 Page 25-26 · 炒股的金钥匙 成功的传家宝
  source_quote: |
    "在股市里头，你对任何人、任何机构，都不要相信，只能相信一个东西，那就是量柱。"
  summary: |
    不把老师、机构、股评或消息当成买卖依据。
    即使是作者本人给出的股票，也不能替代自己的量价判断。
    决策依据要回到盘面中可观察的量柱、价柱和量线。
    这条规则用来防止崇拜、跟单和外部权威绑架判断。
    真正目标是形成自己的标准，而不是复制某个人的指令。
  tags: [anti-authority, volume-first, independent-judgment]

- id: p06
  title: 有限精力只投向量柱量线
  type: principle
  source_chapter: 第5册 Page 170 · 大盘如期重回第四目标线后怎么走（0511收评）
  source_quote: |
    "把有限的工夫用到量柱量线的分析上，你自会受用无穷。"
  summary: |
    不把主要时间花在打探消息、追逐指标和猜测利好上。
    作者认为有用消息最终会反映到量柱量线中。
    因此日常训练应围绕量柱、量线、阴阳、真假和攻防位置展开。
    这不是否认外部信息，而是规定优先级。
    当消息与盘面冲突时，候选规则倾向先服从盘面证据。
  tags: [volume-line, no-rumor, focus]

- id: p07
  title: 看不准时不要动
  type: principle
  source_chapter: 第1册 Page 44 · 看准大方向，破解回马枪
  source_quote: |
    "看准了就放它一枪，看不准时不要动。"
  summary: |
    交易前先判断大方向，局部机会必须服从大方向。
    如果只知道可能有回马枪，却不能确认尺度和时间，就先等。
    宁可错过一段不确定波动，也不在没有把握时主动暴露风险。
    这条规则适用于反弹、抄底、追击和换股之前。
    它把“不交易”定义为一种有效动作。
  tags: [wait, confirmation, no-action]

- id: p08
  title: 谷底线有效跌穿即出货待机
  type: principle
  source_chapter: 第1册 Page 50 · 用“谷底线”预测跌势
  source_quote: |
    "谷底线一旦形成，是不能轻易跌穿的，如果一旦有效跌穿，最好是出货待机。"
  summary: |
    谷底线不是只用来找支撑，也用来识别失败。
    一旦关键谷底线被有效跌穿，原来的防守假设失效。
    此时优先动作是出货、离场、等待新机会。
    不要因为曾经有支撑意义，就继续幻想它会自动恢复。
    适用于底部结构、反弹结构和关键筹码区被击穿时。
  tags: [exit-rule, valley-line, invalidation]

- id: p09
  title: 跌破平衡线看跌出货
  type: principle
  source_chapter: 第1册 Page 51-52 · 中国建筑谷底线跌势分析
  source_quote: |
    "无论股价跌破哪道平衡线，都应该看跌。即使第一道平衡线没有看跌出货，在第二道平衡线也应该看跌出货。"
  summary: |
    平衡线是攻防边界，不只是画图参考。
    股价跌破平衡线，先按看跌处理，而不是继续寻找乐观解释。
    如果第一道线没有执行，第二道线必须补执行。
    这条规则强调二次机会不能再拖延。
    适用于关键支撑线、平台线、精准线被连续跌破的场景。
  tags: [balance-line, exit-rule, defense]

- id: p10
  title: 双阴出货
  type: principle
  source_chapter: 第1册 Page 75 · “双阴出货”的技术妙用（0620讲座）
  source_quote: |
    "所谓“双阴出货”就是“在碰到连续两个阴线时出货”。注意，应包括“低开高走的假阳线”。"
  summary: |
    连续两根阴线出现时，先按出货信号处理。
    低开高走但本质偏弱的假阳，也纳入“双阴”判断。
    第二根阴线有效跌破第一根阴线收盘价时，应盘中出货。
    该规则的核心不是逃在最高点，而是避免进入连续下跌。
    可与大阴出货、分时绿量峰和中轴线跌破配合使用。
  tags: [double-yin, exit-rule, sell-signal]

- id: p11
  title: 量线取点必须自然统一
  type: principle
  source_chapter: 第1册 Page 90 · E线取点答疑
  source_quote: |
    "平衡线的取点必须遵循“天然法则”，要求取点“自然而然”，不要“人工雕饰”。"
  summary: |
    画线不能为了支持自己的预判而随意移动取点。
    上行找实顶，下行找实底，标准先于结论。
    同一个取点标准要同时用于大盘和个股，不能凭好恶变换。
    如果线位来自人工修饰，它就不能作为进出依据。
    这条规则是所有量线交易规则的前置约束。
  tags: [line-drawing, standardization, no-bias]

- id: p12
  title: 踩稳量线大胆搞
  type: principle
  source_chapter: 第2册 Page 115 · 西藏城投分时图分析
  source_quote: |
    "关于“什么时候搞的问题”，前面讲的三线是重要依据。粗略地讲，可以概括为一句话：踩稳量线大胆搞。"
  summary: |
    好股票也要等到合适时机，不能只因题材或形态好就介入。
    三线和量线是判断“什么时候做”的核心依据。
    如果价格没有踩到平衡线，上方高点又逐步降低，不宜介入。
    踩稳量线后再动手，才能把机会和风险放到同一边界里。
    适用于分时介入、回踩买入和反弹确认。
  tags: [entry-rule, volume-line, timing]

- id: p13
  title: 阳胜进，阴胜出
  type: principle
  source_chapter: 第3册 Page 27 · 九阴真经逃命法宝
  source_quote: |
    "如果价柱量柱双阴胜阳，你就必须赶紧逃，这就叫阴胜阳，快逃亡！"
  summary: |
    同时观察价柱和量柱，不只看 K 线颜色。
    双阳胜阴，可以适当介入；单边胜则先观察。
    双阴胜阳时，优先逃命，即使跑错也先保护本金。
    如果第二天重新阳胜阴，再有效跨过阴顶，可重新杀回。
    这条规则用于急跌、阴克阳、高位转弱和股灾式行情。
  tags: [yin-yang, exit-rule, capital-preservation]

- id: p14
  title: 跳空阴出干净
  type: principle
  source_chapter: 第3册 Page 27-28 · 九阴真经逃命法宝
  source_quote: |
    "跳空阴出现之后的走势，往往是一字跌停！所以，必须跑，最好一开盘就跑，跑错也要跑。"
  summary: |
    如果前一日阴胜阳没有出来，次日跳空低开就是最后逃命机会。
    可给一小时确认原则，但一小时内不能翻红就要离场。
    该规则强调做大概率，不为小概率反包冒系统性风险。
    跳空阴后不要恋战，也不要等完整反弹证明自己正确。
    适用于急跌开盘、股灾、个股高位破位和恐慌盘。
  tags: [gap-down, exit-rule, emergency]

- id: p15

- id: p16
  title: 不见信号不挂弦
  type: principle
  source_chapter: 第4册 Page 285 · 周五或有大动作，关注夹改房地产
  source_quote: |
    "主力不动我们就不要动。关注不等于介人。不见信号不挂弦。"
  summary: |
    关注某个板块或股票，不等于立刻买入。
    只有主力行为出现，才进入操作准备。
    没有信号时，研究、观察、设线即可，不挂买入动作。
    该规则防止把“值得关注”误读为“现在介入”。
    适用于题材板块、政策预期和盘前关注名单。
  tags: [watchlist, no-premature-entry, signal]

- id: p17
  title: 准备减仓不等于立即执行
  type: principle
  source_chapter: 第5册 Page 112-114 · 只要不破此线，不要急于减仓 / 继续准备减仓，但勿操之过急
  source_quote: |
    "准备归准备，不见出货信号是不必减仓的，但有必要把多只股票缩减为几只股票。"
  summary: |
    风险临近时先做准备，不等于立刻清仓。
    先压缩持股数量，确保真正信号出现时能快速撤退。
    减仓和清仓不是一回事，不能混用。
    出货信号应盯住预设防线，而不是被担心情绪驱动。
    适用于牛市冲高、目标位附近和震荡加剧阶段。
  tags: [position-management, preparation, sell-signal]

- id: p18
  title: 上攻乏力减仓，下跌乏力加仓
  type: principle
  source_chapter: 第5册 Page 116 · 第三目标位附近操盘策略
  source_quote: |
    "只要指数不能迅速过线，我们就要采取“上攻乏力时减仓，下跌乏力时加仓”的战术。"
  summary: |
    关键线附近不看情绪，看攻防力度。
    上攻不能迅速过线，说明多方后劲不足，应减仓。
    下跌到关键区间后乏力，说明空方不足，可择机加仓。
    这个规则把仓位调整绑定到线位和力度，而不是涨跌本身。
    适用于目标位、阻力线、回踩线和盘中攻防。
  tags: [position-management, attack-weakness, support]

- id: p19
  title: 顶部3121分级减仓
  type: principle
  source_chapter: 第5册 Page 118 · 用顶部3121战法享受牛市盛宴
  source_quote: |
    "若有一个标准出现，减仓三一位；若有两个标准出现，再减仓二一位；三个标准到齐，即全部减仓。"
  summary: |
    顶部风险不是一次性全有或全无，而是分级出现。
    一个见顶标准出现，先减三一仓位。
    两个标准出现，再减二一仓位。
    三个标准齐备，执行全部减仓。
    这条规则把见顶判断转化成仓位动作，避免犹豫或过早清仓。
  tags: [top-signal, 3121, staged-reduction]

- id: p20
  title: 底仓也要等信号
  type: principle
  source_chapter: 第9册 078 · 精准回踩预报值，静待伏击信号现（0510收评兼0511预报）
  source_quote: |

  summary: |

    底仓只能“适量”，不能因恐惧踏空而重仓。
    有效 V 型、确认线和量波结构共同决定是否参与。
    适用于连续下跌后的试探性建仓。
  tags: [bottom-position, confirmation, no-rush]

- id: p21
  title: 切勿盲目跟风追高杀低

  source_quote: |

  tags: [anti-herd, no-chasing, trade-plan]

- id: p22
  title: 权重不领衔，不加大仓位
  type: principle
  source_chapter: 第9册 114 · 价升量缩收新高，闭月羞花看路桥（0630收评兼0703预报）
  source_quote: |
    "只要大金融不能带头冲关，我们就要在上攻乏力时适时减仓或调仓。"
  summary: |
    普通股突破往往需要权重或核心板块领衔。
    如果关键阻力位前缺少大金融、大建设等主力板块发力，不宜加大仓位。
    上攻乏力时先减仓或调仓，等真正领衔过峰再考虑加仓。
    这条规则把仓位大小和市场主攻力量绑定。
    适用于指数冲关、板块轮动和过峰保顶行情。
  tags: [leader-confirmation, position-management, sector-leadership]
